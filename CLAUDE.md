# MesaPronta

Antes de qualquer tarefa, leia:
1. @CONSTITUICAO.md — regras do produto que não mudam sem decisão do dono.
2. @HANDOFF.md — como rodar (`npm start`, Node 22.5+, sem `npm install`), mapa dos arquivos, dados, API e pendências.

Resumo do que nunca fazer: expor dados de um cliente para outro, linkar o `/admin`, commitar `data/` ou senhas,
integrar pagamento ou tirar a etiqueta "Em ajuste" sem o dono pedir.
